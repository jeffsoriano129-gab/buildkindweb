# BuildKind Web — website

Static HTML site. All pages live in `public/`.

- Edit header, footer & icons: `public/assets/layout.js`
- Styles: `public/assets/styles.css` · Behaviour: `public/assets/main.js`
- Preview locally: `npx serve public` then open http://localhost:3000
- Deploy: push to GitHub (auto-deploys if connected in Cloudflare) or run `npx wrangler deploy`
