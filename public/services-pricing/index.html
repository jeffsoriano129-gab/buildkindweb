Transparency

What's included—and what isn't

Package prices cover the development work explicitly listed in the written quote.

Included in your quote

  • The pages and features listed for your package
  • Responsive layout for desktop, tablet & mobile
  • Contact or inquiry form integration using an agreed service
  • Basic on-page SEO setup
  • Basic launch checks for the agreed scope
  • Anything else the written quote specifically lists

The client pays third-party providers directly wherever possible and should own the accounts. If BuildKind Web helps configure an account, the access and responsibilities will be agreed in advance.

Not included unless quoted

  • Domain registration or renewal
  • Hosting, server, or other infrastructure fees
  • Paid email services
  • Premium themes, plugins, builder licences, or stock assets
  • Third-party form, booking, CRM, payment, or automation subscriptions
  • API usage charges
  • E-commerce, membership, booking, or custom application functionality
  • Copywriting, translation, extensive data entry, or sourcing images
  • Advanced SEO campaigns, ongoing content marketing, or ranking guarantees
  • Ongoing maintenance after the agreed handover
